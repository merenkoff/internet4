Preamble

This software is published in the spirit of the Open Internet 4.0 movement. The authors believe that digital tools must respect user sovereignty: devices must work without continuous corporate permission, data must be portable, and software must be auditable, repairable, and forkable.

The source code is open for study, personal use, and community contribution. However, it may not be used to build systems that contradict these values. Using this software to create products with remote kill switches, forced vendor lock-in, or barriers to user ownership is explicitly prohibited.

Full manifesto: https://own-net.com/

Данное программное обеспечение публикуется в духе движения Open Internet 4.0. Авторы считают, что цифровые инструменты должны уважать суверенитет пользователя: устройства должны работать без постоянного корпоративного разрешения, данные должны быть переносимыми, а программное обеспечение — проверяемым, ремонтопригодным и доступным для форкинга.

Исходный код открыт для изучения, личного использования и участия сообщества. Однако он не может использоваться для создания систем, противоречащих этим ценностям. Использование данного ПО для создания продуктов с удалёнными выключателями, принудительной привязкой к поставщику или барьерами для прав владения пользователями прямо запрещено.

Полный манифест: https://own-net.com/

Дане програмне забезпечення публікується в дусі руху Open Internet 4.0. Автори вважають, що цифрові інструменти повинні поважати суверенітет користувача: пристрої повинні працювати без постійного корпоративного дозволу, дані повинні бути переносними, а програмне забезпечення — перевірюваним, придатним до ремонту та форкування.

Вихідний код відкритий для вивчення, особистого використання та участі спільноти. Проте він не може використовуватися для створення систем, що суперечать цим цінностям. Використання даного ПЗ для створення продуктів з віддаленими вимикачами, примусовим прив'язуванням до постачальника або бар'єрами для прав власності користувачів прямо заборонено.

"Closed System"

  1. implements remote kill switches or requires continuous third-party authorization for basic operation of user-owned devices or software;
  2. locks user data in proprietary formats without providing a documented, machine-readable export mechanism;

«Програмне забезпечення»
означає вихідний код, скомпільовані двійкові файли, документацію та будь-які пов'язані файли, що розповсюджуються за даною ліцензією.

  1. реалізує віддалені вимикачі або вимагає постійної авторизації третьою стороною для базової роботи пристроїв або програм, що належать користувачеві;
  2. блокує дані користувача у пропрієтарних форматах без надання задокументованого, машиночитаного механізму експорту;
  3. перешкоджає користувачам у перевірці, зміні або заміні програмного забезпечення на обладнанні, яке їм належить;
  4. створює штучні бар'єри сумісності там, де існують відкриті альтернативи, з метою прив'язки до постачальника;
  5. відстежує або передає активність користувача без явної, усвідомленої та відкличної згоди користувача.
